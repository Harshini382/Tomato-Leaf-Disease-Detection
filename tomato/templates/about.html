Algorithms

Method 1 — Feature-based (GLCM + RF)

Hand-crafted texture and statistical features are extracted from CLAHE-enhanced grayscale images. A Random Forest classifier is trained on these compact descriptors for interpretable, stable predictions.

Method 2 — Combined (GLCM + MobileNetV2)

Combines handcrafted GLCM/statistical features with deep features from a MobileNetV2 backbone. Concatenated feature vectors are classified with an ensemble (RandomForest / XGBoost / LightGBM) to improve discrimination.

Method 3 — Full Pipeline & Comparison

Full training and evaluation pipeline: extract both GLCM and deep features, compare multiple classifiers, and select the best model by F1/robustness. Provides performance analysis and confusion-matrix based selection.
