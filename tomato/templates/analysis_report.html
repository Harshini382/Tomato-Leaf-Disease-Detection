Key MobileNetV2 Innovations

Inverted Residuals

Skip connections between bottleneck layers for better gradient flow

Linear Bottlenecks

Linear activation before pooling to preserve important features

Width Multiplier

Trade-off between accuracy and computational cost (α=1.0)

ReLU6 Activation

Bounds activations for numerical stability in mobile devices

Step 1: Color Space Conversion

RGB → BGR

OpenCV reads images in BGR format. PIL loads in RGB, so conversion is necessary.

image = cv2.cvtColor(image, cv2.COLOR_RGB2BGR)

Step 2: Grayscale Conversion

BGR → Grayscale

Reduces computational complexity while preserving texture information.

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

Step 3: CLAHE Enhancement

Contrast Limited Adaptive Histogram Equalization

Improves local contrast and handles illumination variations.

clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
clahe_image = clahe.apply(gray)
clipLimit: 2.0 (contrast limiting factor) tileGridSize: (8, 8) (grid of 8×8 tiles)

Step 4: Resizing

Original → 224×224

Standard input size for MobileNetV2 architecture.

resized = cv2.resize(clahe_image, (224, 224))

Step 5: Normalization

Pixel Values → [0, 1]

Standardizes input for neural network training.

normalized = resized.astype(np.float32) / 255.0

Step 6: Channel Expansion

Grayscale → 3-Channel RGB

MobileNetV2 expects RGB input, so expand single channel to three.

processed = cv2.cvtColor((normalized * 255).astype(np.uint8), 
                               cv2.COLOR_GRAY2RGB)

⚠️ Limitations & Future Improvements

Current Limitations

  • Requires clear, well-lit images for best results
  • May not detect early-stage diseases with subtle symptoms
  • Performance varies with image quality and resolution
  • Limited to 10 disease classes (may miss new variants)
  • No severity assessment within each disease class

Future Improvements

  • Implement multi-task learning for severity scoring
  • Add attention mechanisms for interpretability
  • Expand dataset with more disease variants
  • Deploy edge-compression for mobile devices
  • Integrate temporal analysis for disease progression
  • Add explainability via Grad-CAM visualization
